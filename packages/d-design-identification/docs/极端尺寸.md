# 极端尺寸组件与版式规则

源版本1.0.0；整编模块1.0.1，2026-11-11。端外传播；口号仅作品牌识别。常规M版与主次信息口号规则不进入本模块。

## 1. 变量与来源

W、C分别为画布成品宽、高，B=min(W,C)，单位统一为px或mm。D为滴滴笑脸图形可见高度，不是画布高度。m=共用边距倍数×D，现有快照为1D。T为扣除边距和品牌保留区后的文字宽度。候选缩放k=B/2126，t=min(k,T/1600)。

连续坐标以左上为原点，x向右、y向下。栅格可见边界采用左/上包含、右/下不包含。像素字号不能直接当作pt；确需换算时必须已知输出DPI。

来源标签：用户确认、规范明确、正文与示意、既有组件快照、实现建议。样稿或候选值不升级为品牌硬约束。用户条件与规范冲突时列出问题，不静默覆盖。本轮二维码是可选功能的业务关闭，不与规范示例冲突。

## 2. 范围和文案

| 项目 | 约束 | 来源 |
|---|---|---|
| 横版 | W/C=6 | 用户确认 |
| 竖版 | W/C=1/6 | 用户确认 |
| 主标题 | 必填、总计≤10字 | 10字为用户确认；必填继承制作流程 |
| 副标题 | 总计≤16字，可为空 | 16字为用户确认；选填继承已有组合约定 |
| 二维码 | 不绘制、不占位、不留空间、不生成扫码说明 | 用户最新确认 |

规范极特殊类别包括横版6:1及更长、竖版1:4及更长；本包**仅启用固定6:1和1:6**。其他极长比例报未支持，不能回退到普通默认标识尺寸。

计数候选约定：NFC归一化，去首尾空白，换行不计；内部空格、标点、数字和字母按字素计数，用Intl.Segmenter，不用UTF-16长度。10/16是总量，不是每行容量。前后端必须一致，真实字体宽度另验。

常规M版12字上限不继承。旧项目URL可继续作为元数据，但不传二维码函数；极端物料表单隐藏二维码项，检查中标记“按本模板不适用”。

## 3. 图文区域与图片

| 档位 | 信息区 | 图片区 | 形式 |
|---|---:|---:|---|
| S 画面优先 | 1/3 | 2/3 | 分割 |
| M 图文平衡 | 1/2 | 1/2 | 分割 |
| L 信息优先 | 2/3 | 1/3 | 分割 |
| XL 全画面 | 叠加文本安全区 | 全画面 | 不绘制橙色分割底 |

横版沿宽分割，竖版沿高分割。可交换图文前后顺序，但不改变档位比例、不翻转文字或拉伸图片。默认信息左/下沿用源模块默认流程；特殊竖版示例优先信息在上，故顺序是候选设置，需在方案页明确展示并供用户确认。

独立品牌识别区不等于S/M/L信息区，不能额外偷偷扣除或相加。图片保留原色、主体与焦点，不加黑色蒙层或自动压暗。裁不下时换图、调整用户确认的裁切或人工处理，不静默扩图。

## 4. 标识大小和统一边距

| 参数 | 横版6:1 | 竖版1:6 |
|---|---|---|
| 默认标识推荐高度D | C/7 | W/8 |
| 依据 | B.4.8，PDF第250页 | B.4.2，PDF第243页 |
| 安全边距m | 共用参数×D，快照为1D | 同一个共用参数×D |
| 口号最小高度 | 不小于D | 不小于D |

“边距与其他模板相同”落实为同一个参数和公式，不是所有成品用同一像素值。标识推荐高度与安全下限分开：偏离推荐值不自动等于品牌违规，但需要另一个明确批准的尺寸配置。本运行时只计算表中默认配置，不接收请求随意传入更小高度。

素材保持可见比例。PNG透明画布不是可见边界或已经批准的安全区。当前Logo可见宽高比约5.110424，口号约5.223368；换版本需核对边界和摘要。

口号使用标准短下划线，不另画通栏横线。当前口号尺寸计算以整个可见资产为准，含短下划线；若规范高度按文字本体判定，需另提供文字本体边界核验。整组件达到D不能直接证明文字本体已达到D。

## 5. 品牌柱锚点

运行时启用品牌柱。默认锚点是模板配置，来源有标记，仍需视觉确认。

横版：标识组左上(m,m)，口号可在右上形成横向品牌柱或左下形成竖向品牌柱，默认右上。普通标识高D时，右上口号坐标为(W-m-口号宽,m)。联合组高于D时同排口号垂直中心对齐，整组边界满足m。

竖版：标识组与口号在同一垂直中心轴，上下分别距画布m，可对调。默认标识在下、口号在上。组坐标((W-组宽)/2,C-m-组高)，口号坐标((W-口号宽)/2,m)。对调不旋转或镜像素材。

文本不能侵入品牌组件1D保护带。背景照片不因存在就自动算作前景碰撞。其他口号信息层级的1.5H等规定不混入本次仅识别场景。

## 6. 文字候选参数

没有极端尺寸可编辑样稿。以下从共享组件的候选基准继承，文字宽度1600作为本模块覆盖值，**不是极端尺寸PDF字号，也不是极端尺寸PSD实测值**。

| 参数 | 主标题 | 副标题 |
|---|---|---|
| 字体 | 汉仪旗黑65S，候选 | 汉仪旗黑50S，用户指定版本 |
| 字号 | 200t | 100t |
| 相邻基线距离 | 字号×1.2 | 字号×1.3 |
| 额外字距 | 0em，保留字体字偶距 | 0em，保留字体字偶距 |
| 行数上限 | 2行，候选 | 2行，候选 |
| 总字数 | ≤10，已确认 | ≤16，已确认 |

主副标题逻辑框间隔112k；副标题为空则没有该间隔和空框。50S是字体版本，不是字号50。禁止假粗体、压扁或拉长字形。

文本区先在信息区扣除m，再让出相交品牌组件及1D保护带；XL用画布安全区。t由画布、档位、品牌排列、信息区顺序和联合标识占用确定，**不随文案长短改变**。超宽、超高、超行或超字数时提示修改，不自动缩字或裁掉文字。

约束模块不实测字体。布局器须补偿ascent/descent/bearing，真实分行；输出字体ID、字号、行距、字距、行数、最宽行宽、缺字数量、可见边界和主副标题逻辑间距。逻辑框顶部不能直接当Canvas默认基线。没有真实测量，文字项只能待复核。

## 7. 联合标识

滴滴为主要联合方、位于最左，支持0/1/2个合作方。伙伴顺序来自用户确认，不由AI重排。

- 合作方可见高0.8D～1.2D；超出需品牌审核，不自动放大。
- 每两个标识之间为0.5D空白＋0.55D批准联乘符号＋0.5D空白，合计1.55D。
- 保持各自可见宽高比；联乘符号引用批准资产，不用任意字体X/×。
- 组宽=滴滴宽+Σ(1.55D+伙伴宽)，组高为子组件最大可见高，整组满足边距。
- 放不下时明确阻断，不挤压、不减少规定间距、不擅自调小D。需要设计确认的新尺寸配置或人工处理。

实算：竖版W=1000，D=125，安全宽750。当前滴滴宽约638.80，加1:1、高125的合作方后组宽约957.55，超过750。因此模块能报告冲突，不保证默认推荐尺寸下每个联合组都可自动排入。

## 8. 其他规范形式

**独立品牌识别区：**6:1横版参考W/6宽，1:6竖版参考C/6高；竖版只能顶部或底部，不得拆成多段。该品牌区与图文区不同。当前模块返回参考尺寸，未启用对应组合渲染；后续需要明确其与SML图文区的组合方式。

**标识口号特殊组合：**PDF第247页（页脚实际标A.4.5）、B.4.9和B.4.10限定于特殊比例或特定素材。引用批准的完整组合，保持内部排列、连接符、间距、线段、配色与比例，按整体可见边界放置。现未提供批准资产，assetId为空；不能用散件临时拼接。主次信息口号通栏横线仍不属于本范围。

第247页竖版特殊完整组合图示保护空间为1.5D，B.4.9横版组合图示为1D；它们不是普通品牌柱的同一种组件。竖版特殊组合若启用，其1.5D保护区与当前共用1D画面边距存在冲突，应先明确对应配置，不能静默削减保护区。本轮默认品牌柱不受该未启用组件影响。特殊组合内部间隔的正文与图示存在表达差异，保留完整批准资产，不由程序自行选一个数字重拼。

## 9. 校验、交付和版本

每个尺寸分别检查：输入、文案、画布、图文区域、品牌组边界、口号大小、文字实测容量、前景碰撞、保护区、二维码禁用。图片主体裁切、实际识别效果、配色、素材用途另做视觉复核。

结果为通过/失败/待复核/不适用。数值比较使用短边×0.000001消除浮点误差，**不是品牌允许偏差**；不使用统一5%自动宽容。

候选字体和视觉验收完成前只称预览。当前模块不生成或检验印刷文件、出血、CMYK、专色、安装遮挡或生产质量。业务审核与下载由网站原流程管理，保存需求快照、规则版本、Git提交和摘要；文案、素材、模板或尺寸修改均使旧预览失效。
