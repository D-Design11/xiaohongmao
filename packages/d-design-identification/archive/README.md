# 来源档案

这里只放追溯资料，不作为网站运行时输入。

- `evidence/regular/psd-measurements.json`：原PSD完整文字、矩阵和图层测量。
- `evidence/regular/measurements-summary.csv`：上述测量的可读摘要。
- `evidence/extreme/`：原包的六张规范证据图。
- `source-records.json`：两个输入包的逐文件摘要，便于确认原件没有被本轮改动。

没有重复带入旧检查报告、旧manifest、历史几何示意或可重算示例输出。新报告在 `development/results/`，新清单在根目录。原始两个文件夹保持原样，未删除。
