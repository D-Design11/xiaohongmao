# 模板中的画面延展 · v1.2.0

2026-11-12 用户确认：先按完整模板测试，再部署网站并更新仓库。本次增加画面延展策略与已确认测试素材的索引；字号、边距、品牌柱和图文比例保持既有规则。

## 规则

先读取模板实际 `imageRegion`，确定主体大小、位置，再裁切非关键背景并延展缺口。人物不能为了装入整张原图而被缩小成小图。最终背景必须铺满整个图片区；不允许灰边、纯色占位边、模糊、镜像或重复拼贴作为完成结果。

6:1 横版的 S/M/L/XL 图片区比例分别为 4:1、3:1、2:1、6:1；1:6 竖版分别为 1:4、1:3、1:2、1:6。不能拿整张物料的比例代替图片区比例。

人物原图可见部分、姿态和服饰优先保留；不自动补画原图未出现的身体部位。本次已授权的两张测试主视觉中，橙色手写文案允许随构图裁切，保留的原字不允许重写或续写笔画。授权按原图摘要记录，不扩大到系统标题、Logo 或其他素材。

扩图只处理背景，系统标题、副标题、Logo 和识别口号仍由模板引用原始资产与字体排版。候选背景需人工核对人物、字迹、道路、光影和接缝；未执行的像素级保护检查不能标为通过。扩图不能解决原人物清晰度不足。

## 本次网站实际能力

当前确认的一条链路是：「每一程都有惊喜」原图 → 1:6 竖向长旗 → M → 上半 1:3 扩图背景、下半橙色信息区，标识与口号按模板排版，不含二维码。

预先生成并由用户接受的背景作为网站资产保存，通过原图 SHA-256、画布比例、M 模板和实际图片区比例共同匹配；网站从该背景动态生成当前文案的预览与 PNG。该背景的几何与外观已用于用户确认，不代表原图人物或字迹达到像素级锁定，也不是印刷生产认证。

素材索引见 [approved-image-extensions.json](../references/approved-image-extensions.json)，策略见 [image-extension.json](../rules/image-extension.json)，纯数据匹配器见 [image-extension.mjs](../runtime/image-extension.mjs)。索引包含二进制文件摘要、网站资产路径与已确认模板样稿路径；图片文件由网站资产库持有，不重复放入 Skill。

网站未在本轮接入新的自动扩图 API。没有匹配背景的素材显示「待扩图」，并提供换用适配素材或人工确认裁切的操作；不会伪装为已经自动扩图。背景已与目标区等比匹配时可直接使用，不需要重复扩图。人物识别、保护蒙版、自动生成及像素级保护合成留待真实服务接入。

## 追溯与版本

原图或模板比例改变后，匹配与确认重新检查。只修改活动标题等系统文字时复用已经确认的背景，生成新项目结果。历史项目保留原规则与生成文件；新项目使用 v1.2.0。未来自动扩图上线时，需要单独验证提供方限制、保护蒙版和人工验收流程。
